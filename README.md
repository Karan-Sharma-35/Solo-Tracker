# Solo-Tracker

## Project Overview
Solo Tracker is a personalized health application designed to manage a carb-cycling dietary strategy and an integrated fitness routine. The application helps users balance high-carb and low-carb days to optimize energy levels for specific physical activities.

## Purpose
The project was created to solve the challenge of manual macro-tracking and workout scheduling. By automating the rotation between nutritional phases, the app ensures consistency in a complex dietary regimen while providing a clear roadmap for weekly physical performance.

## Technologies used
HTML5/CSS3: Structured and styled for a mobile-first responsive experience.
JavaScript: Logic for dynamic tracking and state management.
Web App Manifest: Configured as a Progressive Web App (PWA) to allow for home-screen installation and offline accessibility.

## Challenges
PWA Implementation: A significant challenge was ensuring the manifest.json and icons were correctly configured to be recognized as an installable app across different mobile operating systems.
Design for Utility: I focused on a minimalist CSS approach to ensure the tracker was fast and functional in a gym or kitchen environment where quick data entry is vital.
